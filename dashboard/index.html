      Méthodologie

      Lire ces chiffres avec prudence

      • Estimations modélisées. La Banque mondiale combine des enquêtes ménages (DHS, MICS, enquêtes nationales) et un modèle pour les années sans enquête. Un saut brutal signale souvent une nouvelle enquête plutôt qu'un vrai changement : Sénégal 2022→2024 (+15 pts), Burkina Faso 2023→2024 (+12 pts), Mali 2017→2018 (+16 pts) puis 2023→2024 (−5 pts).
      • Données manquantes. L'accès rural n'est pas publié certaines années (Mauritanie depuis 2013, Burkina Faso 2015–2021, Guinée 2000–2005, Gambie 2018–2019, Mali certaines années). Ces cases restent vides (« — ») : aucune valeur n'est interpolée.
      • Calculs. Habitants sans électricité = population × (1 − accès total). Rythme = gain moyen annuel sur les 5 dernières années. Moyenne simple = moyenne des 8 pays ; moyenne pondérée = par la population.
      • Ce que ces données ne disent pas. Avoir accès ne garantit ni la qualité ni la continuité du service (délestages), ni le coût pour les ménages. Indicateurs utiles pour aller plus loin : coupures (SAIDI), consommation par habitant, mix électrique, tarifs.
      Source : Banque mondiale, indicateurs EG.ELC.ACCS.ZS, EG.ELC.ACCS.UR.ZS, EG.ELC.ACCS.RU.ZS, SP.POP.TOTL. Pipeline : API → DuckDB (raw → staging → marts) → Parquet. Cliquez sur un pays pour le suivre.
